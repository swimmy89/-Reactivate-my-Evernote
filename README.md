# My Evernote Diary

Evernoteからエクスポートした `.enex` ファイルを読み込み、日記としてまた閲覧できるようにするための、自分専用のシンプルなWebアプリです。

## 特徴

- `.enex` ファイル(1つでも複数でもOK)をドラッグ&ドロップまたは選択して読み込み
- 本文中の画像・添付ファイルもEvernote独自のハッシュ参照を解決して表示
- チェックボックス(`en-todo`)や暗号化セクション(`en-crypt`)にも対応
- 日付順の一覧表示、タグ絞り込み、全文検索
- 一度読み込んだ内容はブラウザの IndexedDB に保存され、次回以降は再アップロード不要
- **すべての処理はブラウザ内で完結し、どこにもデータを送信しません**(サーバーレス)

## 使い方

```bash
npm install
npm run dev
```

ブラウザで表示されたURLを開き、`.enex` ファイルを選択してください。

## ビルド

```bash
npm run build
```

`dist/` ディレクトリに静的ファイルが生成されるので、GitHub Pages や Netlify、あるいはローカルで `npm run preview` して使うことができます。
